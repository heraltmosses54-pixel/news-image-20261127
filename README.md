A dense broadsheet of the world's news on Friday 27 November 2026, drawn
with pure Python 3 standard library — no Pillow, no network, no fonts
beyond a hand-written 5x7 bitmap font.

`main.py` writes `entry.png` (1024x1024, deterministic) to
`MAKEFUN_OUTPUT_DIR` if set, otherwise the current directory:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
